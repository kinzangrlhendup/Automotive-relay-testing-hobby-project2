# Hardware

I will keep the electronic design files in this directory.

- `ltspice/` will contain simulations for individual circuit blocks.
- `kicad/` will contain the complete schematic and PCB design.
- `socket-adapters/` will contain the interchangeable relay adapter designs.

I will simulate and bench-test the protected power input, coil driver, current measurement and contact load before combining them into the main PCB.
