# Relay Compatibility Register

I will use this register to document every relay package that I want the tester to support. I will not create a socket footprint from an unscaled sales photograph. Before finalising an adapter, I will verify the physical relay, terminal pattern and dimensions from a sample or reliable engineering drawing.
